# 🏛️ ออกแบบเสาคอนกรีตเสริมเหล็ก ตาม ACI 318-19 (Streamlit)

เว็บแอปสำหรับออกแบบ/ตรวจสอบเสา คสล. หน้าตัดสี่เหลี่ยมและวงกลม ตามมาตรฐาน **ACI 318-19** (หน่วย SI)

## วิธีใช้งาน

```bash
pip install -r requirements.txt
streamlit run app.py
```

1. กรอกข้อมูลที่แถบด้านซ้าย: หน้าตัด → วัสดุ → เหล็กเสริม → ความชะลูด
2. ใส่แรงกระทำประลัยหลายกรณีในตาราง (เพิ่ม/ลบแถวได้)
3. ดูผลทันทีในแท็บ: สรุปผล, Interaction P–M, Biaxial Mx–My, หน้าตัด, ความชะลูด, แรงเฉือน, รายงาน
4. ใช้ **"ช่วยเลือกเหล็กเสริมอัตโนมัติ"** เพื่อหาเหล็กยืนที่น้อยที่สุดที่ผ่าน
5. ดาวน์โหลดรายการคำนวณ (HTML) และผลตรวจสอบ (CSV)

เลือกหน่วยกำลังวัสดุ MPa / ksc และหน่วยแรง kN / tonf ได้

## ขอบเขตการคำนวณ

| หัวข้อ | ข้อกำหนด ACI 318-19 |
|---|---|
| แรงอัดร่วมแรงดัดสองทาง: strain compatibility, εcu = 0.003, Whitney stress block, β1 | 22.2, Table 22.2.2.4.3 |
| φ แปรผันตาม εt (tied 0.65 / spiral 0.75 → 0.90) | Table 21.2.2 |
| Po, Pn,max = 0.80Po (ปลอกเดี่ยว) / 0.85Po (ปลอกเกลียว) | 22.4.2 |
| ตรวจสอบโมเมนต์สองแกนด้วย load contour ที่ระดับ Pu (ทุกทิศทางแกนสะเทิน) | 22.2 |
| ความชะลูด kLu/r, การขยายโมเมนต์ (nonsway) / δs (sway), M2,min | 6.2.5, 6.6.4 |
| แรงเฉือน Vc รวมผลแรงอัด, Vs, Av,min, ระยะเรียงสูงสุด | 22.5, 10.6.2, 10.7.6.5 |
| ρg 1–8 %, จำนวนเหล็กขั้นต่ำ | 10.6.1.1, 10.7.3.1 |
| ระยะช่องว่างเหล็กยืน | 25.2.3 |
| ขนาด/ระยะเรียงเหล็กปลอก, การค้ำยันเหล็กยืน (150 mm) | 25.7.2 |
| ปลอกเกลียว ρs, ระยะเกลียว 25–75 mm | 25.7.3 |

**เครื่องหมาย:** แรงอัดเป็นบวก, Mux = โมเมนต์รอบแกน x (ดัดตามด้าน h), Muy = โมเมนต์รอบแกน y (ดัดตามด้าน b)

**ไม่ครอบคลุม:** ข้อกำหนดแผ่นดินไหวพิเศษ (Chapter 18), คอนกรีตมวลเบา, หน้าตัดรูปทรงอื่น

## โครงสร้างไฟล์

- `app.py` — หน้า UI Streamlit
- `aci318_column.py` — ตัวคำนวณตาม ACI 318-19 (ไม่ขึ้นกับ Streamlit)
- `report.py` — สร้างรายการคำนวณ HTML
- `tests/` — ทดสอบด้วย `pytest` (รวมการเทียบกับการคำนวณมือ)
