# 🏗️ ออกแบบคานและเสาคอนกรีตเสริมเหล็ก (Streamlit)

เว็บแอปหลายหน้า (เลือกหน้าที่แถบด้านซ้าย):

- **ออกแบบคาน คสล.** — ตาม **มยผ. 1103 (วิธีกำลัง)** หรือ **ACI 318-19**
- **ออกแบบเสา คสล.** — หน้าตัดสี่เหลี่ยม/วงกลม ตาม **ACI 318-19**

## วิธีใช้งาน

```bash
pip install -r requirements.txt
streamlit run app.py
```

## หน้าออกแบบคาน

1. เลือกมาตรฐาน (มยผ. 1103 / ACI 318-19) และหน่วย (ksc/MPa, kN/tonf)
2. กรอกหน้าตัด (สี่เหลี่ยมหรือตัว T), วัสดุ, เหล็กปลอก
3. กำหนดแรง: **จากน้ำหนักบรรทุก** (ช่วงเดียว / ปลายต่อเนื่องด้านเดียว / ต่อเนื่องสองด้าน / คานยื่น, รวมน้ำหนักคานเองอัตโนมัติ)
   หรือ **กรอก Mu, Vu เอง**
4. จัดเหล็กบน/ล่าง (สูงสุด 2 ชั้น) และระยะปลอก แยก "ที่รองรับ" กับ "กลางช่วง" — หรือกด **ออกแบบเหล็กเสริมอัตโนมัติ**
5. ดูผลในแท็บ: สรุปผล, แรงดัด (แผนภาพความเครียด/แรง), แรงเฉือน, หน้าตัด, แรงภายใน & การโก่งตัว, ระยะฝังยึด, รายงาน (HTML/CSV)

| หัวข้อ | มยผ. 1103 (อิง ACI 318-99) | ACI 318-19 |
|---|---|---|
| น้ำหนักบรรทุกประลัย | U = 1.4D + 1.7L | U = 1.4D, 1.2D + 1.6L |
| กำลังดัด | strain compatibility, Whitney block, β1 (รองรับเหล็กรับแรงอัด/ตัว T/2 ชั้น) | เหมือนกัน |
| φ ดัด | 0.90 | ตาม εt (Table 21.2.2) |
| เหล็กสูงสุด / ความเหนียว | As ≤ 0.75Asb + As′fs′/fy | εt ≥ 0.004 (9.3.3.1) |
| เหล็กต่ำสุด | max(0.25√fc′, 1.4)·bw·d/fy หรือ 4/3 As,req | เหมือนกัน (9.6.1) |
| φ เฉือน, Vc | 0.85, Vc = (1/6)√fc′·bw·d | 0.75, Table 22.5.5.1 (ρw, size effect λs) |
| Vs,max, ระยะปลอก, Av,min | 2/3√fc′bwd, d/2 (d/4), bw·s/(3fyt) | 0.66√fc′bwd, d/2 (d/4), max(0.062√fc′, 0.35)bw·s/fyt |
| การโก่งตัว | h,min (Table 9.5a), Ie แบบ Branson | h,min (Table 9.3.1.1), Ie แบบ Bischoff (24.2.3.5) |
| ระยะฝังยึด | ACI 318-99 12.2.2 | Table 25.4.2.3 |
| อื่น ๆ | ระยะช่องว่างเหล็ก, ควบคุมรอยร้าว, skin reinforcement, ความกว้างปีกตัว T | + ระยะขาปลอกตามแนวกว้าง (9.7.6.2.2) |

แรงออกแบบจากน้ำหนักบรรทุกใช้วิธีสัมประสิทธิ์ของ ACI (ใช้ได้เมื่อ ≥ 2 ช่วง, ช่วงต่างกัน ≤ 20%, LL ≤ 3DL)
Vu ที่รองรับคิดที่ระยะ d จากหน้าจุดรองรับ, โซนกลางช่วงใช้ Vu ที่ L/4

**ไม่ครอบคลุม (คาน):** แรงบิด, ข้อกำหนดแผ่นดินไหว (มยผ. 1301/1302, ACI Ch. 18), คานลึก, คอนกรีตมวลเบา

> หมายเหตุ: โหมด มยผ. 1103 ใช้ข้อกำหนดตาม ACI 318-99 ซึ่งเป็นพื้นฐานของ มยผ. 1103 — ควรตรวจทานกับฉบับมาตรฐานที่ใช้จริง

## หน้าออกแบบเสา

1. กรอกข้อมูลที่แถบด้านซ้าย: หน้าตัด → วัสดุ → เหล็กเสริม → ความชะลูด
2. ใส่แรงกระทำประลัยหลายกรณีในตาราง (เพิ่ม/ลบแถวได้)
3. ดูผลทันทีในแท็บ: สรุปผล, Interaction P–M, Biaxial Mx–My, หน้าตัด, ความชะลูด, แรงเฉือน, รายงาน
4. ใช้ **"ช่วยเลือกเหล็กเสริมอัตโนมัติ"** เพื่อหาเหล็กยืนที่น้อยที่สุดที่ผ่าน
5. ดาวน์โหลดรายการคำนวณ (HTML) และผลตรวจสอบ (CSV)

เลือกหน่วยกำลังวัสดุ MPa / ksc และหน่วยแรง kN / tonf ได้
