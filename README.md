## หน้าออกแบบคาน

1. เลือกมาตรฐาน (มยผ. 1103 / ACI 318-19) และหน่วย (ksc/MPa, kN/tonf)
2. กรอกหน้าตัด (สี่เหลี่ยมหรือตัว T), วัสดุ, เหล็กปลอก
3. กำหนดแรง: **จากน้ำหนักบรรทุก** (ช่วงเดียว / ปลายต่อเนื่องด้านเดียว / ต่อเนื่องสองด้าน / คานยื่น, รวมน้ำหนักคานเองอัตโนมัติ)
   หรือ **กรอก Mu, Vu เอง**
4. จัดเหล็กบน/ล่าง (สูงสุด 2 ชั้น) และระยะปลอก แยก "ที่รองรับ" กับ "กลางช่วง" — หรือกด **ออกแบบเหล็กเสริมอัตโนมัติ**
5. ดูผลในแท็บ: สรุปผล, แรงดัด (แผนภาพความเครียด/แรง), แรงเฉือน, หน้าตัด, แรงภายใน & การโก่งตัว, ระยะฝังยึด, รายงาน (HTML/CSV)

| หัวข้อ | มยผ. 1103 (อิง ACI 318-99) | ACI 318-19 |
|---|---|---|
| น้ำหนักบรรทุกประลัย | U = 1.4D + 1.7L | U = 1.4D, 1.2D + 1.6L |
| กำลังดัด | strain compatibility, Whitney block, β1 (รองรับเหล็กรับแรงอัด/ตัว T/2 ชั้น) | เหมือนกัน |
| φ ดัด | 0.90 | ตาม εt (Table 21.2.2) |
| เหล็กสูงสุด / ความเหนียว | As ≤ 0.75Asb + As′fs′/fy | εt ≥ 0.004 (9.3.3.1) |
| เหล็กต่ำสุด | max(0.25√fc′, 1.4)·bw·d/fy หรือ 4/3 As,req | เหมือนกัน (9.6.1) |
| φ เฉือน, Vc | 0.85, Vc = (1/6)√fc′·bw·d | 0.75, Table 22.5.5.1 (ρw, size effect λs) |
| Vs,max, ระยะปลอก, Av,min | 2/3√fc′bwd, d/2 (d/4), bw·s/(3fyt) | 0.66√fc′bwd, d/2 (d/4), max(0.062√fc′, 0.35)bw·s/fyt |
| การโก่งตัว | h,min (Table 9.5a), Ie แบบ Branson | h,min (Table 9.3.1.1), Ie แบบ Bischoff (24.2.3.5) |
| ระยะฝังยึด | ACI 318-99 12.2.2 | Table 25.4.2.3 |
| อื่น ๆ | ระยะช่องว่างเหล็ก, ควบคุมรอยร้าว, skin reinforcement, ความกว้างปีกตัว T | + ระยะขาปลอกตามแนวกว้าง (9.7.6.2.2) |

**Load combination เลือกได้** (ทั้งหน้าคาน และหน้าคานต่อเนื่อง): ตามมาตรฐานที่เลือก / 1.4D + 1.7L / 1.2D + 1.6L /
กำหนดตัวคูณ DL, LL เอง — แยกจากมาตรฐานที่ใช้คำนวณ φ และเหล็กสูงสุด และตรวจ 1.4D เพิ่มเสมอเมื่อตัวคูณ DL < 1.4

แรงออกแบบจากน้ำหนักบรรทุกใช้วิธีสัมประสิทธิ์ของ ACI (ใช้ได้เมื่อ ≥ 2 ช่วง, ช่วงต่างกัน ≤ 20%, LL ≤ 3DL)
Vu ที่รองรับคิดที่ระยะ d จากหน้าจุดรองรับ, โซนกลางช่วงใช้ Vu ที่ L/4

**ไม่ครอบคลุม (คาน):** แรงบิด, ข้อกำหนดแผ่นดินไหว (มยผ. 1301/1302, ACI Ch. 18), คานลึก, คอนกรีตมวลเบา

> หมายเหตุ: โหมด มยผ. 1103 ใช้ข้อกำหนดตาม ACI 318-99 ซึ่งเป็นพื้นฐานของ มยผ. 1103 — ควรตรวจทานกับฉบับมาตรฐานที่ใช้จริง

## หน้าคานต่อเนื่อง (Singly/Doubly) — จากไฟล์ Excel

ทำงานแบบเดียวกับไฟล์ `Beam_Design_Singly_Doubly.xlsm` (INPUT → ANALYSIS → DESIGN → OUTPUT) หน่วย ตัน-เมตร / ksc / cm
และ **นำเข้าไฟล์ .xlsm เดิมได้โดยตรง** (อ่านแผ่น INPUT และช่องสีเหลืองที่แก้ไว้ในแผ่น DESIGN)

- วิเคราะห์ Direct Stiffness (2 DOF/จุด) สูงสุด 10 ช่วง: จุดรองรับ Pin / Fixed / Free / Column (stiffness เสาบน-ล่าง 4EI/H),
  ตัดโมเมนต์ที่จุดรองรับ (คานเดี่ยวต่อกัน), น้ำหนัก UDL / สามเหลี่ยม-คางหมู / แรงจุด, Pattern LL และ 1.4DL
- ออกแบบทุกช่วง 3 ตำแหน่ง (ซ้าย/กลาง/ขวา) เลือก Singly/Doubly อัตโนมัติ, ตรวจหน้าตัดจริงด้วย strain compatibility,
  ออกแบบเหล็กปลอก; แก้ Ø เหล็ก / จำนวนชั้น / จำนวนเส้น / เหล็กปลอกได้ ("ช่องสีเหลือง")
- **วาดคานแบบ SUTStructor:** เลือกรูปแบบคาน (คานเดี่ยว / ต่อเนื่อง / คานยื่น / ต่อเนื่อง + ยื่น / คานเดี่ยวต่อกัน)
  หรือ **วาดคานเอง**: แถบเครื่องมือวางจุดรองรับ (Pin / Fixed / เสา) บนแนวคาน, ต่อช่วงหรือคานยื่นเลยปลายคาน,
  ลากจุดรองรับเปลี่ยนความยาว (snap), คลิกตัวเลขพิมพ์ความยาว, ตัด/ต่อโมเมนต์, ลบจุด (รวมช่วง),
  ลากวาดน้ำหนักแผ่ / คลิกวางแรงจุด / เพิ่มพื้นและผนัง (DL/SDL/LL/Wu), ย้อนกลับ/ทำซ้ำ —
  หรือคลิกช่วง/จุดรองรับแล้วกรอกใต้รูป
  (`beam_canvas.py`, `components/beam_editor/`) — ตารางแบบ Excel ยังอยู่ใน "ข้อมูลละเอียดแบบตาราง"
- **รายการน้ำหนักใต้คานแต่ละช่วง** (`beam_loads.py`) เพิ่มได้ไม่จำกัด และพิมพ์สูตรได้ทุกช่อง:
  พื้น (กรอกขนาด S × L + ความหนา → One-way / Two-way และด้านที่คานรองรับคิดให้อัตโนมัติ หรือเลือกเอง),
  ผนัง/กว้างรับ, น้ำหนักแผ่ (a–b), สามเหลี่ยม/คางหมู, แรงจุด — แต่ละรายการใส่ DL/LL (ใช้งาน) หรือ Wu (ประลัยแบบ Excel)
- **แยก SDL ออกจาก DL**: DL = น้ำหนักคาน + พื้น (คิดให้อัตโนมัติ), SDL = วัสดุปูผิว ฝ้า งานระบบ ผนัง —
  กรอกได้ทุกรายการน้ำหนัก แสดงแยกในรูปคาน แผนภาพ และแรงปฏิกิริยา • ตัวคูณ SDL = ตัวคูณ DL หรือกำหนดเอง
  • envelope = fD·DL + fSD·SDL + fL·LL (Pattern LL) และ 1.4(DL + SDL)
- เลือกหน่วยแรง ตัน หรือ kN
- **แท็บ DESIGN SHEET** (`beam_sheet.py`, `beam_sheet_report.py`, `beam_sheet_xlsx.py`): นำ Mu และ Vu สูงสุดจากผลวิเคราะห์ไปออกแบบเหล็กจริง
  ทีละหน้าตัด (ทุกช่วง ซ้าย/กลาง/ขวา) ตามแบบฟอร์ม Beam-Singly / Beam-Doubly
  - เลือก **อัตโนมัติ / Singly / Doubly** ได้ (อัตโนมัติ: Singly เมื่อ ρ ≤ 0.75ρb, Doubly เมื่อเกิน หรือเมื่อเหล็กจริงตรวจแบบ Singly ไม่ผ่าน)
  - เหล็กเมนกรอกเป็นตาราง (ด้าน ดึง/อัด, ชั้นที่, จำนวน, Ø) เพิ่มแถวได้ไม่จำกัด ชั้นเดียวกันใส่หลายขนาดได้ —
    d, d′ = จุดศูนย์ถ่วงของเหล็กทุกชั้น • ปุ่มให้โปรแกรมคำนวณเหล็กเบื้องต้น (ไม่เกิน 4 ชั้นดึง/3 ชั้นอัด, ขยาย Ø เมื่อชั้นไม่พอ)
  - ตรวจ **% เหล็กรับแรงดึง = As/(B·H) ≤ 2 %** และ **ช่องว่างเหล็กเมน = (B − 2·cover − Øปลอก·ขา − ΣnØ)/(n − 1) ≥ 6 cm**
    ของทุกชั้น (ปรับเกณฑ์ได้)
  - เหล็กปลอก 2 โซน (2H จากหน้าเสา / กลางคาน) เลือก Ø และ **จำนวนขา** ได้ พร้อมสวิตช์ For EQ
  - ดาวน์โหลดแบบฟอร์ม (HTML พิมพ์ A4) และ **ไฟล์ Excel ที่ทุกค่าเป็นสูตร** (แก้ช่องสีฟ้าแล้วคำนวณใหม่ได้) ทีละแผ่นหรือทุกช่วง
  - ผลตรงกับไฟล์ Excel ของแบบฟอร์มทุกค่า และไฟล์ Excel ที่ส่งออกคำนวณได้ตรงกับโปรแกรม (`tests/test_beam_sheet.py`)
- แผนภาพรายช่วงแบบรายการคำนวณมือ: น้ำหนัก W ของแต่ละช่วง, แรงปฏิกิริยา Ry, SFD และ BMD พร้อมค่าที่ปลายช่วง/ค่าสูงสุด
  (เลือกกรณี Factored / Service / DL / LL)
- ไม่ต้องกด RUN — คำนวณใหม่อัตโนมัติ; ดาวน์โหลดรายการคำนวณทุกช่วงเป็น HTML (พิมพ์ A4)
- ตรวจสอบแล้วว่าผลตรงกับไฟล์ Excel: แรงภายใน/แรงปฏิกิริยาตรงกับผลของแมโครทุกค่า และค่าในแผ่น DESIGN
  ตรงทุกเซลล์ (ทั้ง ACI 318-99 และ ACI 318-19) — ดู `tests/test_continuous_beam.py`

## หน้าออกแบบเสา

1. กรอกข้อมูลที่แถบด้านซ้าย: หน้าตัด → วัสดุ → เหล็กเสริม → ความชะลูด
2. ใส่แรงกระทำประลัยหลายกรณีในตาราง (เพิ่ม/ลบแถวได้)
3. ดูผลทันทีในแท็บ: สรุปผล, Interaction P–M, Biaxial Mx–My, หน้าตัด, ความชะลูด, แรงเฉือน, รายงาน
4. ใช้ **"ช่วยเลือกเหล็กเสริมอัตโนมัติ"** เพื่อหาเหล็กยืนที่น้อยที่สุดที่ผ่าน
5. ดาวน์โหลดรายการคำนวณ (HTML) และผลตรวจสอบ (CSV)

เลือกหน่วยกำลังวัสดุ MPa / ksc และหน่วยแรง kN / tonf ได้
